Browsergator is open-source software for connecting MCP-compatible AI agents to a browser that the operator has deliberately made available. It is a tool, not an autonomous authority, and it is provided on an “as is” and “as available” basis.

## Accessibility and assisted use

Browsergator may be useful as an assistive interface for people who cannot reliably operate a browser themselves. The person or organisation operating the browser, account, device, and connected services remains responsible for deciding what the agent is allowed to do. Configure the narrowest practical permissions, review important actions, and keep a human in the loop where the consequences matter.

Delegating an action to an AI agent does not transfer responsibility for that action. The operator is responsible for the instructions supplied, the account and browser context selected, the outcome accepted, and any follow-up required.

## Security and operational limits

AI agents can misunderstand instructions, select the wrong page, produce incorrect content, or fail in unexpected ways. Browsergator does not guarantee that an agent will identify every dangerous page, prompt, dialog, transaction, or data leak. The operator must use least privilege, protect bearer tokens and credentials, isolate browser profiles, inspect logs, and test changes before production use.

The gateway does not guarantee availability, correctness, compatibility, data preservation, transaction completion, or recovery from browser, network, provider, or client failures. A configured safety rule is a defence in depth, not a substitute for authorization and human review.
