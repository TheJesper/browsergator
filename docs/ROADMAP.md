# Roadmap

## 0.1 MVP

Singleton Streamable HTTP, direct CDP connection, target lifecycle, core read/mutation tools, per-page FIFO, runtime leases, protected-tab policy, bounded observations, redaction, audit, health/readiness, mock integration tests.

## 0.2 Client-neutral access

Direct Codex, Claude Code, Gemini CLI, and TeamRoom configuration; stateless stdio bridge; explicit logical agent/task/lease identity independent of MCP client sessions; browser session and browser context diagnostics.

## 0.3 Interaction

Type, key, scroll, drag, dialogs, popup ownership, uploads/downloads, richer DOM targeting, visual stability, and deterministic `natural` mode. Basic selector/text click and CSS-selector fill are available in the current gateway.

## 0.4 DevTools depth

Storage/cookies, WebSocket detail, interception/mocking, performance traces, screencast, emulation, coverage, debugger/stack enhancements, and controlled response-body persistence.

## 0.5 Isolation and identity

Browser contexts, signed client identities, per-reader authorization, durable leases/idempotency, external event storage, and optional multi-process failover while preserving one active controller.

## 0.6 Cloak

Long-lived CloakBrowser worker, coherent identity profiles, capability negotiation, human handoff for CAPTCHA, and per-origin traffic budgets.
